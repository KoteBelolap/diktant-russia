# Сайт Всероссийского гражданско-патриотического диктанта
## «Моя любовь, душа моя – Россия!» – V сезон – 2026

Статический прототип и фронтенд для переноса в раздел сайта Президентской
академии на 1С-Битрикс. Проект написан на семантическом HTML, CSS и ванильном
JavaScript: без фреймворков, сборщиков и внешних клиентских зависимостей.
Все рабочие пути относительные и подходят для размещения в подкаталоге.

## Актуальные страницы демо

1. [Главная](https://kotebelolap.github.io/diktant-russia/index.html)
2. [Материалы для подготовки](https://kotebelolap.github.io/diktant-russia/materials.html)
3. [Новости](https://kotebelolap.github.io/diktant-russia/news.html)
4. [Страница теста](https://kotebelolap.github.io/diktant-russia/test.html)

GitHub Pages работает в режиме `demo` и берёт текущее время с устройства.
До 5 ноября 2026 года страница теста закономерно показывает экран ожидания.
В бою время обязательно приходит от сервера Академии.

## Даты и формат

- начало: **5 ноября 2026 года, 10:00 по московскому времени**;
- окончание: **8 ноября 2026 года, 23:59 по московскому времени**;
- три категории: школьники 5–11 классов, студенты вузов и СПО, взрослые
  и пенсионеры;
- боевой вариант: **30 вопросов за 40 минут**;
- тренировочные тесты включаются администратором вручную;
- сертификат отправляется на электронную почту в течение 48 часов после
  успешной регистрации.

## Текущее поведение участника

### Основной диктант

1. До старта кнопки «Принять участие» заблокированы. В момент старта они
   активируются без перезагрузки.
2. Перед вопросами участник указывает пол, возраст, регион, организацию и сам
   выбирает категорию участия.
3. ФИО и электронная почта до теста не запрашиваются.
4. Кнопка «Далее» доступна только после ответа на текущий вопрос. На последнем
   вопросе результат открывается только после заполнения всех ответов либо
   автоматически по окончании времени.
5. Балл считает сервер. Правильные ответы в боевой браузер не передаются.
6. После результата участнику даётся 120 секунд на решение:
   - «Дозаполнить данные» – ФИО, почта и согласия для сертификата;
   - «Отказаться» или отсутствие решения – запись результата без ФИО со
     значением «не заполнено».
7. Дедлайн считается по реальному времени от завершения теста. Перезагрузка
   страницы его не продлевает.
8. После анонимной записи позднее дозаполнение запрещено по `attemptId`.
9. Повторное прохождение основного диктанта с того же браузерного профиля
   блокируется. Тренировочные попытки не ограничены.

### Хранилище браузера

| Ключ | Назначение |
|---|---|
| `diktant_attempt_done_v1` | завершённая основная попытка, анкета, балл, `attemptId`, состояние регистрации/анонимной записи |
| `diktant_registrations_demo` | локальный журнал регистраций только для статичного демо |
| `diktant_score` | балл для отдельной страницы регистрации |

`localStorage` – только клиентская страховка и демонстрационная механика. В
production сервер самостоятельно контролирует попытку, дедлайн и
идемпотентность по `attemptId`.

## Режимы `demo` и `production`

Режим задаётся шаблоном страницы, а не доменом и не параметром URL.

### Demo

Если мета-тега режима нет, используется `demo`:

- время берётся с устройства;
- при отсутствии API лениво загружается сокращённый
  `question-bank-demo.js`;
- балл демо-вопросов считается в браузере;
- регистрация и дубль-проверка имитируются в `localStorage`;
- организации ищутся в статичных JSON.

Демо-банк сейчас содержит 14 вопросов на каждую основную категорию и 8
тренировочных. Это проверка интерфейса, а не полный вариант из 30 вопросов.

### Production

Шаблон каждой боевой страницы обязан вывести в `<head>`:

```html
<meta name="diktant-mode" content="production">
<meta name="server-time" content="2026-11-01T12:34:56+03:00">
```

В production:

- отсутствие `server-time` блокирует тест – часы устройства не используются;
- файл с правильными ответами не запрашивается;
- вопросы и балл приходят только от API;
- ответ `GET /api/test` должен содержать ровно 30 вопросов и `attemptId`;
- организации ищутся только через `/api/orgs`;
- отказ API не подменяется локальным успехом, нулевым баллом или локальной
  регистрацией;
- пользователю показывается честная ошибка и безопасный повтор запроса;
- при ошибке анонимной записи состояние помечается как `anonPending`, а
  сертификатная регистрация остаётся закрытой после дедлайна.

На боевой сервер **не копировать** `assets/js/question-bank-demo.js` и
статичные справочники, если поиск полностью обслуживает `/api/orgs`.

## Серверные API

| Метод и адрес | Назначение |
|---|---|
| `GET /api/test?cat=school|student|adult|training` | `attemptId` и 30 вопросов без правильных ответов |
| `POST /api/test/submit` | проверка ответов, `{score,max}` и фиксация времени завершения |
| `POST /api/check-duplicate` | точная дубль-проверка регистрационных данных |
| `POST /api/register` | именная или анонимная регистрация по `attemptId` |
| `GET /api/orgs?q=…&region=…` | топ-40 организаций по релевантности |

Полные контракты, коды ошибок и серверный двухминутный дедлайн описаны в
[CMS-GUIDE.md](CMS-GUIDE.md).

## Вопросы

Банк каждой боевой категории хранится только на сервере и должен содержать
примерно 50 или больше заданий. Сервер выбирает 30, перемешивает вопросы и
варианты и исключает поле `right` из ответа браузеру.

Формат записи банка:

```json
{
  "id": "sch-014",
  "cat": "school",
  "type": "single",
  "tag": "История",
  "q": "Текст вопроса?",
  "media": {
    "kind": "image",
    "src": "/upload/question.jpg",
    "alt": "Описание изображения"
  },
  "opts": ["Вариант 1", "Вариант 2", "Вариант 3", "Вариант 4"],
  "right": [1]
}
```

`media` необязательно. Поддерживаются изображения и MP4 H.264. Поле `right`
используется только сервером.

## Справочник организаций

Текущая официальная выгрузка содержит **64 618 уникальных организаций**.
Форма предлагает 90 вариантов территории: 89 субъектов России и «За пределами
Российской Федерации».

Обновление справочника:

```bash
# заменить docs-dev/reference/orgs-source.xlsx
python3 tools/xlsx-to-orgs.py
```

Конвертер:

- проверяет известные регионы;
- создаёт `r01.json`…`r90.json`, `none.json`, `all.json`, `manifest.json`;
- добавляет населённый пункт в название, когда его нельзя понять из названия;
- детерминирован: повторная сборка одного Excel даёт те же байты.

## Сертификат

API возвращает полный номер вида `ПА/НОТА-26/000123`. На фоне сертификата
префикс `ПА/НОТА-26/` уже напечатан, поэтому динамическое поле `regnum`
содержит **ровно шесть цифр без префикса**: `000123`.

Пакет генерации находится в `docs-dev/certificate/`. PDF печатается размером
297×210 мм. Подробности – в `docs-dev/certificate/ALGORITHM.md`.

## Локальный запуск

```bash
python3 -m http.server 8901
# http://127.0.0.1:8901/
```

Чтобы локально проверить состояние мероприятия, временно добавьте в `<head>`
страницы тестовый `server-time`. Для проверки строгого боя добавьте также
`diktant-mode=production` и запустите совместимый API.

## QA

Автономная проверка не требует сторонних Python-пакетов:

```bash
PYTHONDONTWRITEBYTECODE=1 python3 qa/check_repo.py
```

Она проверяет синтаксис JS/Python, JSON, HTML-ID, локальные ссылки, CSS,
справочник организаций, production-защиту и единый шестизначный формат поля
сертификата. Тот же скрипт запускается в GitHub Actions.

## Редакционные правила

1. Обращение к пользователю – «Вы» с большой буквы.
2. Используется среднее тире «–», а не длинное «—».
3. Буква «ё» обязательна.
4. Даты сопровождаются словами «по московскому времени».
5. В пользовательских текстах пишется «Российская Федерация» или «Россия»,
   а не сокращение «РФ».
6. Короткие слова автоматически связывает со следующим словом `typograf.js`.
