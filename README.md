# Сайт Всероссийского гражданско-патриотического диктанта
## «Моя любовь, душа моя – Россия!» · V сезон · 2026

Статический фронтенд, готовый к переносу в 1С-Битрикс: чистый семантический HTML,
современный CSS (без сборщиков и зависимостей), ванильный JS. Работает с любого
подкаталога — все пути относительные. **Сейчас это информативный сайт**: тестовая
часть откроется 5 ноября 2026 в 10:00 по московскому времени (механика готова
и показывается по прямой ссылке, см. раздел 4).

> **Даты проведения: с 5 ноября 2026 года 10:00 до 8 ноября 2026 года 23:59 —
> всегда по московскому времени (считается от времени сервера, не устройства).**

Полное руководство по переносу и управлению контентом — **CMS-GUIDE.md**.

## 2. Реализовано по ТЗ и правкам (август 2026)

- **Даты и время**: старт 05.11.2026 10:00, финиш 08.11.2026 23:59 — по
  московскому времени, от **времени сервера** (мета-тег `server-time`, см. CMS-GUIDE §4;
  без него — демо-откат на часы устройства).
- **Кнопка «Принять участие»**: до старта серая + подпись «Диктант начинается
  5 ноября в 10:00 по московскому времени», ссылки на тест с основных страниц
  отсутствуют; после старта — красная и активная (`data-gate="start"`).
- **Навигация**: полосы разделов сверху и снизу всех страниц в стиле диктанта;
  сайдбар/топбар/дровер удалены полностью.
- **Тест**: 3 возрастные категории; **30 вопросов из банка ~50** — случайная
  выборка и перемешивание вопросов и вариантов (антисписывание); 40 минут;
  вопросы могут содержать **изображения (jpg/png) и видео (mp4 H.264)** — разметка
  поддержана, формат поля описан; на одиночном выборе вопрос перелистывается сам.
  «Назад» интерфейса и браузера ведут логично (History API): к предыдущему вопросу,
  с первого — к выбору категории.
- **Ответы — только на сервере**: в бою вопросы приходят без правильных ответов
  (`GET /api/test`), балл считает сервер (`POST /api/test/submit`). Демо-банк
  с ответами — карантинный `question-bank-demo.js`, в бой не выкладывать.
- **Повторы**: проходить можно сколько угодно раз с одного устройства
  (требование заказчика). Дубли отсеиваются при регистрации: точное совпадение
  ФИО + пол + возраст + регион + организация + категория → окно
  «Вы уже участвовали?» (`/api/check-duplicate`, демо-режим — журнал устройства).
- **Результат**: вердикты по шкале 30 / 25–29 / 15–24 / 0–14
  («Абсолютный победитель!», «Отличный результат!», «Хорошая работа!»,
  «Есть куда расти») + «N из 30 верных ответов». Разбор ответов **не показывается**.
  Регистрационная форма — **сразу под результатом**, без промежуточных экранов.
- **Регистрация**: ФИО, пол, возраст, e-mail, регион (89 субъектов), тип
  организации (6 вариантов ТЗ), образовательная организация с интеллектуальным
  поиском, категория, согласия ОПД. Успех: галочка, «Данные успешно
  зарегистрированы!», адрес жирным, 48 часов, «Спам»/«Нежелательная почта»,
  рег. номер **ПА/НОТА-26/XXXXXX** (ID с добивкой нулями до 6 знаков).
- **Сертификат**: пакет генерации в `docs-dev/certificate/` — фон JPG (300 dpi
  из PDF оргкомитета), HTML/CSS-шаблон с полями (ФИО ×3 строки, балл,
  рег. номер), `fields.json`, `ALGORITHM.md`, демо-PDF.
- **Контент**: новости автоматически подтягиваются (2 последние на главную строкой,
  плашка «Нет актуальных новостей» при пустой ленте); теги убраны; карточки
  приподнимаются при наведении. Статьи/видео — заглушки «Заголовок статьи» /
  «Текст статьи» (тексты переданы оргкомитету Word-документом).
- **Тренировочные тесты**: скрыты до 01.10.2026 (auto), режимы off/on/auto —
  одна настройка; карточки с бейджами «5–11 класс», «ВУЗЫ И СПО», «Личное участие».
- **Редакционные правила**: «Вы» с большой; «–» вместо «—»; без «·»;
  буква «ё»; «Российской Федерации» вместо «РФ»; предлоги не висят
  (авто-Nbsp); «по московскому времени» у всех дат.

## 3. Запуск

```bash
python3 -m http.server 8901    # из каталога site/
# http://127.0.0.1:8901/
```

Состояния гейта проверяются тестовым мета-тегом времени:
`<meta name="server-time" content="2026-11-06T12:00:00+03:00">`

## 4. Демо vs бой

| Что | Демо (сейчас) | Бой (сервер Академии) |
|---|---|---|
| Время старта | часы устройства | `<meta name="server-time">` от Битрикса |
| Вопросы теста | `question-bank-demo.js` ⚠ (удалить!) | `GET /api/test?cat=` — 30 из банка, без ответов |
| Балл | считает браузер | `POST /api/test/submit` |
| Организации | `orgs-data.js` (~690) | `GET /api/orgs?q=&region=` (полный справочник) |
| Дубль-чек | localStorage-журнал | `POST /api/check-duplicate` |
| Регистрация + reg. номер | имитация, номер 000001… | `POST /api/register` → `ПА/НОТА-26/XXXXXX` |
| Сертификат | демо-PDF из пакета | печать шаблона сервером, письмо за 48 ч |

Контракты и правила переноса — в **CMS-GUIDE.md**.
