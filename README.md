# Раздел Всероссийского гражданско-патриотического диктанта
## «Моя любовь, душа моя – Россия!» · V сезон · 2026

Фронтенд предназначен для раздела сайта Президентской академии, например
`https://www.ranepa.ru/nauka/diktant/`. Это не отдельный сайт: при публикации
разметка, стили и сценарии подключаются внутри общего шаблона Академии.

Код написан на семантическом HTML, CSS и обычном JavaScript без сборщика,
фреймворков и внешних клиентских зависимостей. Относительные пути позволяют
размещать раздел в подкаталоге. Основная страница раздела – `main.html`.

## Даты и формат

- начало: **5 ноября 2026 года, 10:00 по московскому времени**;
- окончание: **8 ноября 2026 года, 23:59 по московскому времени**;
- категории: школьники 5–11 классов, студенты вузов и СПО, взрослые и
  пенсионеры;
- основной вариант: **30 вопросов за 40 минут**;
- тренировочные тесты включаются администратором вручную;
- сертификат отправляется на электронную почту в течение 48 часов после
  успешной регистрации.

## Страницы раздела

| Файл | Назначение |
|---|---|
| `main.html` | страница «О диктанте» |
| `materials.html` | материалы для подготовки и тренировки |
| `news.html` | лента новостей |
| `article.html` | шаблон новости или статьи по `?id=…&type=…` |
| `test.html` | анкета, тест, результат и регистрация участника |

Навигация внутри макетов относится только к разделу диктанта. Общие шапку,
навигацию и подвал Академии предоставляет внешний шаблон. Собственные favicon
в проект не входят: значок страницы также задаёт шаблон Академии.

## Сценарий участника

### Основной диктант

1. До начала мероприятия кнопки участия заблокированы. Они активируются в
   момент старта без перезагрузки страницы.
2. Перед вопросами участник указывает пол, возраст, регион, организацию и
   категорию участия.
3. ФИО и электронная почта запрашиваются после завершения теста.
4. Переход к следующему вопросу доступен после выбора ответа. Завершить тест
   можно после заполнения всех ответов либо по окончании времени.
5. В рабочем режиме балл считает сервер; правильные ответы не передаются в
   браузер.
6. После результата участнику даётся 120 секунд на выбор:
   - «Дозаполнить данные» – указать ФИО, почту и согласия для сертификата;
   - «Отказаться» или не выбирать действие – сохранить результат без ФИО.
7. Срок считается от серверного времени завершения и не продлевается после
   перезагрузки.
8. После анонимной записи дозаполнение данных по этой попытке закрывается.
9. Завершённая основная попытка блокирует повторный проход в том же профиле
   браузера. Тренировочные попытки не ограничены.

Отдельной публичной страницы регистрации нет. Форма открывается только внутри
завершённой попытки на `test.html` и связана с `attemptId`, серверным баллом и
двухминутным сроком.

### Локальное хранилище

| Ключ | Назначение |
|---|---|
| `diktant_attempt_done_v1` | состояние завершённой основной попытки |
| `diktant_registrations_demo` | журнал регистраций для локальной проверки |
| `diktant_score` | совместимое локальное значение балла |

`localStorage` поддерживает локальную проверку и интерфейсную страховку.
В рабочем разделе сервер самостоятельно контролирует попытку, срок и
идемпотентность по `attemptId`.

## Режимы выполнения

Режим задаёт шаблон страницы, а не домен или параметр URL.

### Локальная проверка (`demo`)

Если мета-тег режима отсутствует:

- время берётся с устройства;
- при отсутствии API лениво загружается `question-bank-demo.js`;
- балл тестового банка считается в браузере;
- регистрация и проверка совпадений имитируются в `localStorage`;
- организации ищутся в статичных JSON.

Сокращённый банк проверяет интерфейс и не заменяет рабочий набор из 30
вопросов.

### Рабочий раздел (`production`)

Шаблон каждой страницы выводит в `<head>`:

```html
<meta name="diktant-mode" content="production">
<meta name="server-time" content="2026-11-01T12:34:56+03:00">
```

В `production`:

- отсутствие `server-time` блокирует тест;
- файл с правильными ответами не загружается;
- вопросы, балл, организации и регистрация работают только через API;
- `GET /api/test` возвращает ровно 30 вопросов и обязательный `attemptId`;
- ошибка API не подменяется локальным успехом;
- участнику предлагается безопасно повторить неудачный запрос;
- не подтверждённая сервером анонимная запись сохраняет состояние
  `anonPending` до успешного повтора.

На рабочий сервер не копируют `assets/js/question-bank-demo.js`. Статичные
JSON организаций также не нужны, если поиск полностью обслуживает `/api/orgs`.

## Серверные API

| Метод и адрес | Назначение |
|---|---|
| `GET /api/test?cat=school|student|adult|training` | выдача `attemptId` и 30 вопросов без ответов |
| `POST /api/test/submit` | проверка ответов и фиксация результата |
| `POST /api/check-duplicate` | проверка совпадения данных участника |
| `POST /api/register` | именная или анонимная регистрация |
| `GET /api/orgs?q=…&region=…` | поиск до 40 организаций |

Успешная именная регистрация возвращает номер из **ровно шести цифр без
префикса**:

```json
{ "ok": true, "regNumber": "000123" }
```

Полные контракты и коды ошибок приведены в [CMS-GUIDE.md](CMS-GUIDE.md).

## Контент и медиаматериалы

### Новости и статьи

`assets/js/news-data.js` сохраняет три пустых массива, на которые опираются
статические макеты. В 1С-Битрикс эти данные формируют компоненты CMS:
`NEWS_DATA`, `ARTICLES_DATA` и `VIDEOS_DATA`.

### Галереи почётных гостей

Карточка гостя связана атрибутом `data-guest-media` с одноимённым ключом в
`assets/js/guest-media.js`. Элементы содержат только:

```js
{ "kind": "video", "src": "assets/media/guests/example/video-01.mp4" }
{ "kind": "img", "src": "assets/media/guests/example/img-01.jpg" }
```

Подписи к фото и видео гостей не выводятся. В каждой подборке все видео должны
находиться перед всеми фотографиями.

Чтобы вручную добавить материалы гостя:

1. Скопировать исходные файлы в `assets/media/guests/<ключ-гостя>/`.
2. Добавить записи `kind` и `src` в подборку этого гостя в
   `assets/js/guest-media.js`: сначала видео, затем фотографии.
3. Если добавляется новый гость, назначить его карточке на `main.html`
   `data-guest-media="<ключ-гостя>"`.
4. Запустить `python3 qa/check_repo.py` и проверить галерею локально.

Файлы меньше 100 МБ сохраняются без перекодирования. Файл размером 100 МБ или
больше перед публикацией нужно уменьшить ниже этого предела.

RUTUBE используется только для прямой трансляции под таймером. Адрес кнопки
задаётся в `CONFIG.broadcastUrl`, а iframe плеера размещается в `#broadcast`.
Он не относится к видеоматериалам гостей.

`assets/js/image-loader.js` подключён в `<head>` всех страниц. При загрузке или
смене любого изображения прежний кадр скрывается, а до события `load` или
`error` показывается полоска загрузки.

## Справочник организаций

Официальная выгрузка содержит **64 618 уникальных организаций**. В форме
доступны 89 субъектов России и пункт «За пределами Российской Федерации».

Обновление:

```bash
# заменить docs-dev/reference/orgs-source.xlsx
python3 tools/xlsx-to-orgs.py
```

Генератор проверяет регионы, добавляет уточнение населённого пункта при
необходимости и создаёт `r01.json`…`r90.json`, `none.json`, `all.json` и
`manifest.json`. Повторная обработка одного Excel должна давать те же байты.

## Сертификат

Пакет генерации находится в `docs-dev/certificate/`. API, база и динамическое
поле `regnum` используют **ровно шесть цифр без префикса**, например `000123`.
Статический префикс на текущем фоне сертификата не входит в значение номера.
PDF печатается размером 297×210 мм. Подробности приведены в
`docs-dev/certificate/ALGORITHM.md`.

## Локальный запуск

```bash
python3 -m http.server 8901
# открыть http://127.0.0.1:8901/main.html
```

Для проверки рабочего режима нужен совместимый API и мета-теги
`diktant-mode=production`, `server-time`.

## QA

```bash
PYTHONDONTWRITEBYTECODE=1 python3 qa/check_repo.py
```

Проверка охватывает синтаксис JavaScript и Python, JSON, HTML-ID, локальные
ссылки, CSS, справочник организаций, медиагалереи, рабочий режим и единый
шестизначный формат регистрационного номера. Тот же сценарий выполняется в
GitHub Actions.

## Редакционные правила

1. Обращение к участнику – «Вы» с большой буквы.
2. Используется среднее тире «–».
3. Буква «ё» обязательна.
4. Даты мероприятия сопровождаются словами «по московскому времени».
5. В пользовательских текстах пишется «Российская Федерация» или «Россия».
6. Короткие слова автоматически связывает со следующим словом `typograf.js`.
