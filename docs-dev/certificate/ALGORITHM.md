# Генерация сертификата участника — алгоритм для разработчиков

Механика соответствует тому, как это делается в Академии: **фон сертификата
загружается как JPG, тексты формируются скриптом (разметка HTML + CSS)**,
результат печатается в PDF и уходит вложением в письмо.

## Состав пакета (docs-dev/certificate/)

| Файл | Назначение |
|---|---|
| `certificate-bg.jpg` | Фон сертификата, 5834×4125 px (300 dpi из исходного PDF оргкомитета «Сертификат Диктант v3 ИТОГ (3).pdf»), 297×210 мм альбомная. |
| `certificate-template.html` | HTML/CSS-шаблон: фон + позиционированные текстовые поля. Именно его печатает скрипт. |
| `fields.json` | Машинное описание полей: координаты (px и на печати), шрифт, цвет, маски. Единый источник правды для генератора. |
| `ALGORITHM.md` | Этот документ. |
| `certificate-demo.pdf` | Демонстрационный результат (Иванова Мария Сергеевна, 27/30, ПА/НОТА-26/000001). |

## Шаг 1. Исходник фона

Фон один раз экспортируется из PDF оргкомитета:

```bash
# Python + PyMuPDF
python3 -c "import fitz; d=fitz.open('Сертификат ИТОГ.pdf'); \
  p=d[0].get_pixmap(dpi=300); p.save('certificate-bg.jpg', jpg_quality=90)"
```

В бою оргкомитет может прислать фон **без слов-плейсхолдеров**
(«Фамилия Имя Отчество», «XX», «XXXXXX»). Тогда шаблон используется
с классом `clean` — маски-заплатки не рендерятся вообще.
Если фон с плейсхолдерами — маски компенсируют их (см. `coverPlaceholder`
в fields.json): это прямоугольники в цвет фона (`#fbfcf7` справа,
`#0d2a66` слева), поверх которых ложатся настоящие значения.

## Шаг 2. Данные участника

После регистрации (POST /api/register) сервер знает:

```json
{
  "surname": "Иванова", "name": "Мария", "patronymic": "Сергеевна",
  "score": 27, "regNumber": "ПА/НОТА-26/000001"
}
```

Регистрационный номер: `ПА/НОТА-26/` + ID участника из базы,
дополненный нулями слева до 6 знаков. На фон в поле `regnum`
подставляются **только 6 цифр** — префикс уже напечатан на макете.

## Шаг 3. Рендер в PDF

Скрипт подставляет значения в `span[data-field]` шаблона и печатает
страницу в PDF размером ровно 297×210 мм:

```bash
chromium --headless --disable-gpu --no-pdf-header-footer \
  --print-to-pdf=certificate-000001.pdf \
  "certificate-template.html?fio1=Иванова&fio2=Мария&fio3=Сергеевна&score=27&regnum=000001"
```

Внутри шаблона уже заложены `@page { size: 297mm 210mm; margin: 0 }`,
так что PDF получается без полей и колонтитулов — ровно по макету.

Тот же принцип из PHP/Bitrix: рендер через headless-браузер
(chromium/chrome, wkhtmltopdf, dompdf *не* рекомендуем — точность
хуже) либо через headless-инстанс на стороне сервера писем.

## Шаг 4. Контроль качества

1. **Шрифт** Manrope ExtraBold (или Montserrat ExtraBold) должен быть
   встроен в PDF — хранить рядом с шаблоном.
2. **Переполнение**: если ФИО длиннее ~24 символов, уменьшать размер
   шрифта до влезания строки (в fields.json — одна строка на поле).
3. Отчество может отсутствовать — поле `fio3` тогда пустое, вёрстка
   не сдвигается.
4. Итог PDF — одна страница, 297×210 мм, ≤1,5 МБ (jpg-фон).

## Отправка

PDF прикладывается к письму участнику в течение 48 часов после
заполнения регистрационной формы. Текст письма оргкомитет берёт
из CMS (см. CMS-GUIDE.md).
